Angular Core Concepts:
------------------------------------------

1. data binding

    a. interpolation
        -> binding data from component class to template
        in template
        <h1>{{ expression }}</h1>

    b. property binding
        -> binding data from component class to template
        in template
        <img [src]="imageUrl" alt="Product Image">      

    c. event binding
        -> binding events from template to component class
        in template
        <button (click)="addToCart()">Add to Cart</button>


2. directives

   -> re-usable functionality that can be applied to elements in the template

    a. structural directives
        -> change the structure of the DOM by adding or removing elements
        -> examples: *ngIf, *ngFor

    b. attribute directives
        -> change the appearance or behavior of an element
        -> examples: ngClass, ngStyle    

------------------------------------------- 

imp-note:
When component's state changes, 
Angular automatically updates the view to reflect the new state. 
This is achieved through a process called 'change detection', which checks for changes in the component's data and updates the DOM accordingly.
This allows developers to focus on managing the component's state without worrying about manually updating the view.

Componet Lifecycle
-------------------------------

Hooks:
    -> constructor -> called when the component is instantiated.
    -> ngOnChanges -> called when any data-bound property of a directive changes.
    -> ngOnInit -> called once the component is initialized.
    -> ngOnDestroy -> called just before the component is destroyed.



-----------------------------------    
2.Directives
-----------------------------------

-> re-usable functionality that can be applied to elements in the template


- structural directives
    -> change the structure of the DOM by adding or removing elements
    -> examples: *ngIf, *ngFor

- attribute directives
    -> change the appearance or behavior of an element
    -> examples: ngClass, ngStyle


custom directives
    -> developers can create their own directives to encapsulate specific behavior or functionality that can be reused across multiple components. 

e.g highlight directive that changes the background color of an element when hovered over.

ng generate directive highlight --project shop-it-page-v2


------------------------------------
3.Pipes
------------------------------------

-> transform data in the template before it is displayed to the user.

{{expression|pipeName:parameter1:parameter2}}

custom pipes
    -> developers can create their own pipes to encapsulate specific data transformation logic that can be reused across multiple components.

example: price discount pipe that takes a price and a discount percentage and returns the discounted price.

ng generate pipe price-discount --project shop-it-page-v2


-------------------------------------
4.Services
-------------------------------------

-> reusable logic that can be shared across multiple components.

example: 

a product service that fetches product data from an API and provides it to components that need it.
a cart service that manages the state of the shopping cart and provides methods for adding, removing, and updating items in the cart.

ng generate service cart-service --project shop-it-page-v3

How to manage forms in Angular?
https://angular.dev/guide/forms


Terms while working with forms:

1. FormControl
    -> represents a single form control, such as an input field or a select dropdown.
    -> it tracks the value and validation status of the control.
2. FormGroup
    -> represents a group of form controls, such as a form with multiple input fields.
    -> it tracks the value and validation status of the group as a whole.
3. FormArray
    -> represents an array of form controls, such as a list of items that can be dynamically added or removed.
    -> it tracks the value and validation status of the array as a whole.
