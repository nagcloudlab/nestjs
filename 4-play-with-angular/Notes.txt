>ng version

>ng new workspace1 --create-application=false

>cd workspace1

>ng generate application shop-it-page

>cd projects/shop-it-page

-------------------------------------------
Angular Core Concepts:
------------------------------------------

1. data binding

    a. interpolation
        -> binding data from component class to template
        in template
        <h1>{{ expression }}</h1>

    b. property binding
        -> binding data from component class to template
        in template
        <img [src]="imageUrl" alt="Product Image">      

    c. event binding
        -> binding events from template to component class
        in template
        <button (click)="addToCart()">Add to Cart</button>


2. directives

   -> re-usable functionality that can be applied to elements in the template

    a. structural directives
        -> change the structure of the DOM by adding or removing elements
        -> examples: *ngIf, *ngFor

    b. attribute directives
        -> change the appearance or behavior of an element
        -> examples: ngClass, ngStyle    

------------------------------------------- 

imp-note:
When component's state changes, 
Angular automatically updates the view to reflect the new state. 
This is achieved through a process called 'change detection', which checks for changes in the component's data and updates the DOM accordingly.
This allows developers to focus on managing the component's state without worrying about manually updating the view.

Componet Lifecycle
-------------------------------

Hooks:

    -> constructor -> called when the component is instantiated.
    -> ngOnChanges -> called when any data-bound property of a directive changes.
    -> ngOnInit -> called once the component is initialized.
